# Event Reminder System (JavaFX)

A desktop-based Event Reminder application built using Java and JavaFX.

---

## Features

- Add, remove, and search events  
- Mark events as completed or pending  
- View completed events  
- Data persistence using file storage  
- Modern JavaFX GUI with ListView  
- Automatic reminder scheduler  

---

## How to Run

### 1️⃣ Install Requirements
- Java 17 or higher  
- JavaFX 24  

### 2️⃣ Compile

```bash
javac --module-path "PATH_TO_JAVAFX_LIB" --add-modules javafx.controls,javafx.graphics -d out src/com/bablu/reminder/Main.java
